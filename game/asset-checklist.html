上线前资产清点

发行前的最后一关：逐项确认游戏里每一样东西的来源和授权 · 全部勾完才能提审

为什么要做这一步

上线时平台会要求你签知识产权承诺书——承诺所有内容合法，出事自己担。 平时没人查，但作品一旦被推荐、被更多玩家看到，版权方找上门的案例并不少。 这一步课堂内 30 分钟起步，剩余项课后补全，全部勾完之前不提审。

美术素材

本项目已核对 ✓

图、插画、图标、场景素材，每张都能回答：哪来的、许可是什么。

本项目现状：全部美术为 CSS / 内联 SVG 自绘（场景、图标、favicon），无外部图片引用。此项全过。
03

字体

本项目已核对 ✓

字体是独立美术作品，也是被起诉最多的一类。

高危字体名单：微软雅黑（嵌入产品需方正授权）、方正系全部、汉仪系全部、华康系部分。这些东西出现在 @font-face 里就是隐患。
本项目现状：仅系统字体栈（苹方 / 雅黑 / 宋体 / DIN），无任何字体文件打包。保持「永远不打包字体文件」即可。
04

音乐与音效

⚠ 唯一待办

本项目唯一没核对完的资产：bgm.mp3 与 bgm_alt.mp3。

本项目待办：两个 BGM 来自量潮原站，但来源需确认。确认不了就执行第 4 项替换。这是全清单唯一的红灯，处理完即可提审。
05

图标、商店物料

本项目已核对 ✓

提审要交的每张图，都算「美术素材」，规则同第 02 项。

本项目现状：favicon 为内联自绘 SVG；游戏名《量潮模拟经营游戏》为自定名。商店截图待物料制作时生成。
06

证据存档

清点的产出不是「我知道了」，而是留档。将来任何人质询，翻出文件即可。

assets-clearance/
├─ music/
│  └─ bgm-license.png      # 下载页 + 许可证截图
├─ art/
│  └─ （每个外部素材一份来源记录）
├─ fonts/
│  └─ （打包字体时放对应 LICENSE）
└─ NOTES.md                # 每项一行：素材 → 来源 → 许可 → 存档文件
检验标准：清单里每一个素材，都能回答三个问题——哪来的、许可是什么、证据在哪。答不上来的那一项，就是待办。

怎么交

课堂：教师带各组对照本页逐项过一遍，当场能确认的当场勾掉；确认不了的记成待办。 课后：待办项补齐（多数是「存档截图」这种十分钟的小事）。 验收：进度条 17/17 + assets-clearance 文件夹齐全 → 才允许提交审核。
