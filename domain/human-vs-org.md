# 人力资源与组织管理

相邻的两个域，界线以直觉为准：读到一篇判例，第一反应归哪边就落哪边。直觉含糊时再核对归到哪——这条经验带走的是人的成长，还是组织的安排。手段不参与判断：通过真实工作长本事和通过课程学本事，都归到同一处。

## 人力资源

归到人：培训、招聘、选拔、晋升、岗位能力，回答「人怎么带到胜任」。

判例：通过问题发现能力培养产品运营。成长路径写在 Issue 与 PR 的参与里，载体是组织机制，归到的仍是培训职能。

## 组织管理

归到组织：结构、权责、规则，回答「组织靠什么运转」。

判例：组织结构——联盟下设实训基地和研究院，分级训练。

## 回看

按归到哪回看既有落格，需要改的：

- `org/rank.md` 晋升通道写着培养与选拔并用，归到人，偏人力资源，待拆分或迁移。
- 待迁的案例提案：
  - 归到人力资源：招聘、培训、选拔、晋升、岗位能力类。如把课程实践改造成招聘考核、用众包任务连接真实需求训练与选拔、将商务能力从个人经验发展为岗位能力。
  - 归到组织管理：结构、权责、规则类。如按工作阶段分配领导权和责任、把成员发起的积分制发展成组织记录。
