# 资产关系

资产只有三种位置：context 是入口，长期记忆是常驻，archive 是出口。三处放同一批内容，区别只在前两级的顺序。

## 三种结构

context：领域一级，资产二级。

```text
context/<领域>/<资产>/<余下>
```

长期记忆：资产是一级仓库，领域是仓库内部的一级文件夹。

```text
<资产仓>/<领域>/<余下>
```

archive：与 context 基本同构，领域一级，资产二级。

```text
archive/<领域>/<资产>/<余下>
```

## 一次搬迁的三步

1. context 内先整理与校验：内容按「领域 / 资产」放好，校验通过再动。
2. 按既定规则移动：前两段交换，`<领域>/<资产>/<余下>` → `<资产>/<领域>/<余下>`。
3. 到目标仓后二次整理：按目标仓的体例与入口重新组织。

顺序不能变：先整理再移动，先移动再进目标仓整理。

## 三条关系

迁入：context → 长期记忆，交换前两段。

```text
context/<领域>/<资产>/<余下> → <资产仓>/<领域>/<余下>
```

归档：context → archive，结构不变，只换位置。

```text
context/<领域>/<资产>/<余下> → archive/<领域>/<资产>/<余下>
```

归档：长期记忆 → archive，换回领域在前。

```text
<资产仓>/<领域>/<余下> → archive/<领域>/<资产>/<余下>
```

```text
context/<领域>/<资产>/ ──迁入──> <资产仓>/<领域>/
        │                              │
        └──────────归档──────────> archive/<领域>/<资产>/ <──归档──┘
```

## 二十种

context 一种，长期记忆十八类，archive 一种，共二十种。关系只在二十种之间发生。
