# 把晋升路径拆成可观察的阶段

## 方案目标

将成员从参与实训到承担正式工作责任的过程划分为可观察的阶段，明确每个阶段的责任、进入条件和通过条件。

本方案参考实训基地、联盟与公司之间的具体培养实践，不作为统一晋升标准。

## 一、建立成长阶段

**做什么：** 将参与者的成长过程划分为不同阶段。

**怎么做：**

根据具体实践，可参考以下阶段：

| 阶段 | 身份定位 | 主要责任 |
|---|---|---|
| -3 | 初步参与者 | 了解组织、熟悉任务 |
| -2 | 实训参与者 | 在指导下完成基础任务 |
| -1 | 候选成员 | 独立完成任务并承担部分责任 |
| 0 | 达到公司门槛 | 具备进入公司相应岗位的基本条件 |

负数表示距离公司相应标准的阶段差异，不代表能力为负。

在实际使用时，应结合组织情况补充各阶段的具体能力要求，不能只使用数字或头衔区分成员。

**通过条件：**
- 每个阶段都有明确的身份定位。
- 成员能够理解当前阶段的责任。
- 不会将参加实训直接等同于进入公司。

## 二、阶段进入与评估

**做什么：** 根据成员实际表现决定是否进入下一阶段。

**怎么做：**
1. 记录成员参与的任务和项目。
2. 检查任务完成情况、沟通能力和责任承担情况。
3. 根据当前阶段要求判断是否达到进入下一阶段的条件。
4. 对未达到要求者提供具体改进意见。
5. 由相应负责人或组织授权的评审主体确认阶段调整。
6. 保留阶段变更依据。

**通过条件：**
- 阶段调整有具体表现作为依据。
- 成员知道自己为什么通过或暂缓。
- 评估结论可以追溯。

## 三、设置候补成员过渡层

**做什么：** 对已经具备一定能力、但尚未完全适应公司工作的成员设置过渡培养环节。

**怎么做：**
1. 根据实际表现提名候补成员。
2. 明确候补资格对应的责任范围和权限。
3. 对候补成员进行有针对性的系统训练。
4. 通过实际工作观察其适应情况。
5. 达到相应要求后，再考虑进入正式成员阶段。
6. 未达到要求时，继续培养或调整安排。

**通过条件：**
- 候补资格有明确的授予依据。
- 候补成员清楚自己尚未获得的权限。
- 过渡训练能够对应正式岗位的实际要求。

## 四、晋升、调整与退出

**做什么：** 建立阶段变动的记录和反馈机制。

**怎么做：**
1. 成员提出阶段调整申请，或由负责人根据表现提出建议。
2. 收集任务记录和评价依据。
3. 对照阶段要求进行评估。
4. 公布调整结果及对应责任变化。
5. 对长期未参与或不再符合要求的成员，重新确认其参与状态。

**通过条件：**
- 阶段变化有记录。
- 责任和权限随阶段变化同步调整。
- 成员能够了解调整原因。

## 五、定期检查培养效果

重点检查：
- 各阶段成员的实际参与情况。
- 候补成员训练完成情况。
- 晋升后的工作适应情况。
- 阶段设置是否能够真实反映责任变化。

## 适用边界

本案例中已经出现阶段职级说明、候选代表名单、候补资格授予和提名等实践。具体晋升标准、阶段周期和退出规则仍在调整，不能将上述阶段直接理解为已经正式确立的完整制度。本方案是对具体实例的整理，不构成统一晋升标准。
